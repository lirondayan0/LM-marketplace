## Writing a new recipe
1. Show the rule list you extracted from the reference; get a nod if it is unusual.
2. Constants on top (layers, styles, offsets, tolerances) with a comment on where each came from.
3. Locate the element relative to an anchor (title text, block), never absolute coordinates.
4. `--dry` prints the plan; real run backs up and updates the original and can render a PNG.
5. Add the row above, a CHANGELOG line, and any convention to `conventions/`.
