## Which drawing for a hollow-core slab: panel span vs cut (user's explanation of 1-1, 2026-10-06) V
- The plan draws a double arrow (LEADERs on `0_LUHADIM_HEZ`) beside every `D=a+b` label = the **panel span direction** (here E-W). `scripts/plan_cuts.py` reads it.
- **View direction parallel to the span** (cut crosses the panels): the cores show as CIRCLES, the panels run past this beam and do NOT bear on it -> cast edge beam with the hollow-core edge next to it (`ledge_beam.py --kind cast`, gallery 1-1). My first 1-1 was wrong because I drew a solid cast slab; the user's version (cores, topping line, 2 mesh dots) is right.
- **View direction perpendicular to the span** (plane contains the span): panels are seen LENGTHWISE and BEAR on this beam's ledges -> ledge beam (`ledge_beam.py --kind ledge`, gallery 2-2, 3-3, 4-4).
- Check any new plan with `plan_cuts.py` (it prints CORES / LENGTHWISE per cut) before choosing the recipe; never assume solid slabs.
