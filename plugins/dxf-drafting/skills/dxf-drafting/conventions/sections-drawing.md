## 4. Reinforcement rules common to all sections
- **Bar rows are associative ARRAYS** (user, three times): every bar row is an AutoCAD ARRAYRECT so the engineer changes the count with the grip - runs of >= 3 equal-step dots, leftover same-y dots two by two, odd dots loose. `bar_arrays.py FILE --box ...` (accoreconsole, PowerShell not git-bash) is the LAST write step of every round, standard and XREF; leaders still end on the dot centres; a bar-count change does not move leaders or dims. A round is not done before the arrays exist.
- **Slab bar anchorage** (user 2026-10-21 bottom bar, 3-3; 2026-10-24 red cloud on netivot 7-7: *'a solid slab beside a beam: its reinforcement extends 60 into the beam'*): EVERY bar of a solid slab ends **60 from the beam face it enters through** (W-3 if the beam is narrower than 63) - bottom AND top. The only exception: both slab tops FLUSH (one continuous top over the beam) -> the top bar runs through. One-sided slab or stepped tops (different top levels, even by 5) -> the top bar enters 60 (general_beam.py `_flush`; ledge_beam.py solid slab beside a ledge beam: the old ~D top anchor of the 2026-10-15 hand edit is replaced). V on 7-7 (his hand edit: left top bar ends 60 from the left face, 40542.2 for a face at 40482.2). In XREF overlays the slab bars end at the XREF slab end instead (sections-xref.md).
- **Stirrups**: key = width of the stirrup-bearing part (STEM of a ledge beam, B of a cast beam), cm in steps of 5 (15..200, rounded UP). n stirrups of width w spread evenly over (thickness-6): first 3 from one face, last 3 from the other, staggered 5.9 in the detail row; n = 1 -> width = thickness-6. Tables (profile `stirrup_tables`, `dxflib.stirrup_layout`): **standard** (`קורות רגילות Φ12@15`): 15-45 -> 1 x (thickness-6); 50 -> 2x30; 55-60 -> 2x35; 65 -> 2x40; 70-75 -> 2x45; 80 -> 2x50; 85-90 -> 3x35; 95-105 -> 3x40; 110-115 -> 3x45; 120 -> 3x50; 125-130 -> 4x40; 135-145 -> 4x45; 150-160 -> 4x50; 165-180 -> 5x45; 185-195 -> 5x50; 200 -> 5x55. **Transfer** (`קורות טרנספורמציה Φ12/14/16@15`, beams carrying a NEW element; diameter by shear): 15-30 -> 1; 35-60 -> 2 (20..35); 65-90 -> 3 (25..35); 95-120 -> 4 (30..40); 125-150 -> 5 (30..40); 155-180 -> 6 (35..40); 185-200 -> 7 (35..40). V on his examples (standard 85 -> 3x35; transfer 50 -> 2x30; 30 -> 1x24). Table chosen by the MARK (S / SS standard, ST transfer; sections-workflow.md). Drawn BOTH inside the section (n overlapping rectangles, hook ticks at each top-right corner) and in the detail row.
- **Beyond 200** (tables stop): the user's HOOP RULE - one hoop has two branches at most 40 apart, so every width <= 40; `dxflib.stirrup_extend` (progression fitted to 38/38 table rows: a new stirrup every 40 standard / 30 transfer cm, then n++ while w > 40): standard 205 -> 7x40, 250 -> 8x40, 300 -> 10x40; transfer 250 -> 9x40, 300 -> 10x40; a row beyond the table warns loudly (UNVERIFIED, ask). **Decided by the user 2026-10-24: the standard table is kept AS TAUGHT (widths 45/50/55 for stems 70-200 stay); the <= 40 hoop rule applies only to the extension above 200.**

- **Middle steel (ברזל אמצעי)** = the side-face bars between the top and bottom bars; note `2$<d>@<s>` (s = MAXIMUM spacing between face-column dots): section area A = B x H: A < 2000 -> Ø8@20; 2000 <= A <= 10000 -> Ø8@15; A > 10000 -> Ø10@15 (boundary values -> the middle band, ?); beams supporting precast hollow-core -> Ø12@20 whatever the size. `dxflib.mid_steel(B, H, hollow)`; general_beam applies it; existing sheets: `mid_steel_sheet.py` -> `bar_arrays` -> `leader_fit`.
