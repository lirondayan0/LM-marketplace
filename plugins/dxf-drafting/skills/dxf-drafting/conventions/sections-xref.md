# Cross-sections, part 4: SECTIONS ON REVIT XREF GEOMETRY (3841-CON_test, 4238-CON-1008-1009; CURRENT, consolidated 2026-10-23)
Same drawing rules as `sections-drawing.md` (a section is a section); this file holds what differs when the beam / slab / wall outline already EXISTS as XREF geometry and only the reinforcement is added. Confidence is medium unless marked: most rules come from one file and his hand edits.

## 1. What the file is
- The XREF geometry is cached in the BLOCK DEFINITIONS (read it, never edit it). The sections are `... Section - -1 - Section N` heads on a plan XREF `LEV_-nn GD`; a star pair is matched to the nearest numbered head (ambiguous ones flagged). The plan XREF block can be EMPTY in the host: `xref_overlay.py --plan-dxf PLAN.dxf` (the DWG converted with accoreconsole `(command "_.DXFOUT" ...)` run from Python in a short ASCII dir; a `SAVEAS` script hung 300 s).
- `xref_overlay.py` draws REINFORCEMENT ONLY (`ledge_beam.OVERLAY`) over the XREF outline: hollow-core ledge beams, slabs flush with the beam top, ledge both / one side. Slab lines that run OVER the beam count for both sides; an `S-BEAM-1` outline that stops at the slab soffit means beam top = slab top. Wall above a beam -> `xref_wall.py`; sections without an S-BEAM outline or with a wall beside the beam -> `xref_junction.py`; stepped / upstand slabs, no-ledge levels: listed, not drawn; a one-side slab of an unreadable kind: NOT DRAWN instead of a crash.

## 3. The pipeline (this order; work on a COPY in the scratchpad, render every section, then install = snapshot + copy over the file after an mtime check; a PermissionError means CAD has it open: ask him to save + close)
1. `xref_overlay.py FILE [--only N,N] [--dry] [--png] --write` (snapshot first).
2. `xref_extend_bars.py` - slab bars reach the XREF slab end (A-FLOR-1 extreme on that side; far end only; idempotent). **In XREF overlays the bars end exactly at the XREF slab edge** (his red cloud on a bar end; his hand-extended left side agrees) - supersedes the 60 cm length of standard sections.
3. `xref_extend_dots.py` - the transverse-bar dot rows continue: same spacing (20), last dot 0.7 from the slab end (his Sec 9: -25561.4, -25581.4 for end -25582.1). Needs plain dots (arrays hide them), so it runs BEFORE the arrays.
4. `xref_text_clear.py [--vertical]` - a host note never overlaps XREF text (level markers `+nn.nn`, dim texts, titles), XREF lines (outline, wall, dims) or another note (gap >= 1.5): **slide the note LEFT or RIGHT (<= 50) and STRETCH its leader** (shelf + fork lines follow, tips stay on the bars); do NOT lift it up / down - vertical is a reported fallback only (`--vertical`, small lift) when no horizontal place exists (top-bar note beside the XREF level marker). **A leader is never cut**: shelf horizontal, touching every fork, joint = whichever polyline end touches the fork LINEs (assert connectivity before saving); one text per shelf (best overlap); unattached notes are reported; stirrup-detail groups must not sit over XREF dimension lines (put them below the section, by hand).
5. `xref_cores.py FILE --dry`, then `--write --expect MTIME` - ONLY when he asks for the hollow-core voids ('wherever the section cuts through a hollow-core slab, add the slab's voids'): obrounds (sections-drawing.md section 9) on every slab side with a topping line (A-FLOR-MCUT) that meets the stem / wall face without a ledge; scope = all sections, voids only; layer `10_PLADA_HATAH` GREEN ACI 3 (a layer a recipe creates itself defaults to white - set the office colour); idempotent (centre = mean of the obround vertices); ? not checked against the plan's span arrows. Test the write on a scratch copy first.
6. `bar_arrays.py FILE --box <sheet>` LAST, from PowerShell: reinforcement is ALWAYS an array (51 arrays on 3841-CON_test: 29 H, 22 V, 0 loose).
7. **Delete the star marks** (`hat` pairs on `automatic_sections`) of the sections drawn in this run - and only those: `xref_overlay --write` does it at the write step (snapshot first; `--keep-marks` to keep); if a later step fails, restore the marks from the snapshot instead of redrawing them. END STATE: `xref_overlay.read_marks` returns 0 pairs inside `claude_Kontur` for the drawn sections (checked retroactively on 3841-CON_test: 9 pairs of sections 3, 7, 9, 10, 13, 14, 15 deleted); marks of sections not requested, other plans' marks, marks outside the contour and `23_SIM` symbols stay. Report 'deleted N marks of sections ...'. (Standard rounds keep the mark and REPLACE its text by the section number.)
